# Contributing to EAIP

Thank you for your interest in contributing to the Enterprise AI Integration Protocol (EAIP)! We welcome contributions to the technical specification, the governance framework, and the supporting tools.

## Ways to Contribute

1.  **Reporting Bugs**: If you find an issue with the specification or any of the governance documents, please open an issue in the repository.
2.  **Suggesting Enhancements**: We welcome ideas for improving the protocol or the framework. Please open an issue to discuss your suggestions.
3.  **Pull Requests**: If you would like to make a direct contribution, please follow these steps:
    - Fork the repository and create a new branch for your changes.
    - Ensure your changes adhere to the existing style and technical standards.
    - Run the verification suite (\`make check-gsifi-governance\` and \`make verify-framework\`) before submitting.
    - Submit a pull request with a clear description of your changes.

## Development Standards

- **Technical Specification**: Modifications to \`EAIP_Technical_Specification.xml\` must follow the established XML schema and include appropriate versioning and change log entries.
- **Governance Framework**: Documentation in the \`governance/\` directory should remain consistent with the overall framework architecture and cross-referencing system.

## Code of Conduct

All contributors are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
